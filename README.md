# 5-Minute Intro

A reveal.js presentation of Dr. Phoenix Perry's talk, *How Creatives Are Shaping More Equitable AI Futures*. Styled to match the [sandpit collaboration map](https://phoenixperry.github.io/sandpit).

## Run locally

```
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Keyboard

- `→` / `space`: next slide
- `←`: previous
- `f`: fullscreen
- `s`: speaker notes
- `esc`: overview
